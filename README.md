# 挂壁修仙传 · 三和大神挂机版（恶搞限定）

> 世人皆道修仙难，殊不知挂机亦是道。
> 本游戏纯属朋友间恶搞，深藏友情，请谨慎转交给本人（建议配一箱红牛）。

双击 `index.html` 即可开始搬砖（推荐 Chrome / Edge）。

## 玩法

1. **点他的脸** 开始搬砖，赚取魔兽金币；
2. 攒金币在 **家当** 里添置老旧主机、大水管宽带、挂机小号……一路开到搬砖工作室，再到**网吧包夜 → 矿机阵列 → 私服一条龙 → 挂牌上市**；
3. **神装** 里升级机械键盘、宏编程，顺便改善伙食（挂逼面管饱、红牛续命、火腿肠加蛋）；
4. 集齐 **45 个成就**，每个全局产量 +1%；
5. 本局卖出 **1 兆金币** 后，可以 **回村过年**：一切清零，换长辈红包（每封永久 +2% 产量），越回家越强；
6. 每天 **日常** 页刷 3 个搬砖任务，清完领红包。

## 手机适配

这一版专门为手机重做了布局，不是简单把桌面版压窄：

- **应用壳布局**：头部和头像区高度固定，只有右侧面板内部滚动，不会出现"整页滚 + 列表再滚"的双层滚动；
- **头部瘦身**：390px 下头部从 156px 压到 89px（占屏 10.5%），金币数字优先，次要信息胶囊收小，320px 超窄屏自动隐藏标题文字、只留 logo；
- **页签等分**：8 个页签用 `flex:1` 铺满一行，360/320px 也不会溢出或被裁（原来是横向溢出）；
- **热区放大**：所有按钮 ≥36px（买量按钮 38px、页签 44px 高、点击头像 100px）；
- **连点不再被放大**：`html,body,*{touch-action:manipulation}` 全局禁掉浏览器双击缩放（双指缩放、滚动照旧保留），头像周围空白、卡片、按钮、页签全覆盖；按下反馈只缩放内层头像，按钮热区保持 100%，连点不会因为缩小而漏点；存档输入框字号提到 16px，避免 iOS 聚焦时强制放大；
- **触屏手感**：`touch-action:manipulation` 去掉双击缩放延迟，`@media (hover:none)` 下禁用 hover 位移（避免点完"粘"在高亮态）；
- **安全区**：`viewport-fit=cover` + `env(safe-area-inset-*)`，iPhone 刘海与home 指示条不压内容；
- **高度用 `100dvh`**：移动端浏览器地址栏收起/展开时不再裁掉底部；
- **提示改底部**：Toast 在手机上从右上角改成底部通栏，不挡金币数字；
- **横屏矮屏（≤520px 高）**：头像缩到 64px、去掉外圈光环，把高度让给列表（内容区占比从 30% 提到 40%+）。

## 音效延迟（手机）

暴击人声原来每次都是 `new Audio(...).play()`，等于每次暴击都重新建一个媒体播放器：解析文件头、初始化解码器、激活音频会话。桌面实测这一步 25–39ms，手机上还要走硬件音频通路和 iOS 音频会话激活，量级到 100ms+，听起来就是"慢半拍"；而且没在用户手势里解锁过，iOS 上首次播放可能直接被挂起甚至拒绝。

现在：

- **池化复用**：页面加载即建 3+3 个 `<audio>` 实例并 `preload`，暴击时轮转复用，不再新建；
- **手势解锁**：首次 `pointerdown/touchstart/keydown` 时 resume AudioContext，并静音"过"一遍池子元素，把解码与音频通路预热；
- **AudioBuffer 直发**：http(s) 环境下把 mp3 预解码成 `AudioBuffer`，播放时 `createBufferSource().start()`，零元素创建、零解码；
- **不再积压**：`Sound.tone()` 在上下文非 running 时直接丢弃，避免 resume 瞬间一堆音效一起炸；
- **先出声后画特效**：`critFX()` 把发声提到最前面，不再排在 3 次强制重排和 70 个粒子之后。

实测（桌面无头）：池化后 `play()` 到开始播放中位 **6.5–7.5ms**；旧写法每次冷启动 25–39ms。两段语音本身开头静音仅 **20ms**（MP3 编码器固有），解码 14–20ms，不是延迟来源。剩下的物理下限（蓝牙耳机 100–300ms、输出缓冲 ~20–30ms）无法靠代码消除。
